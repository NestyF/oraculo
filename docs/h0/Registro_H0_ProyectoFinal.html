2 Tipo de proyecto

Elige una sola opción. El proyecto debe ser un videojuego o una app móvil; no se aceptan aplicaciones tradicionales (una webapp o app convencional que no sea un juego ni una app móvil). Un videojuego Unity sí puede publicarse como build web.
